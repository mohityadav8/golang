# Golang

A comprehensive repository containing my **Go (Golang)** learning journey, including detailed theory, conceptual explanations, challenging code examples, and hands-on practice programs.

## 📚 About

This repository is organized topic-wise, covering Go fundamentals to advanced concepts. Each topic contains:

- 📖 Detailed Theory
- 💻 Practical Code Examples
- 🧠 Conceptual & Advanced Programs
- ⚡ Practice Exercises

The goal of this repository is to build a strong understanding of Go internals rather than just learning syntax.

## ▶️ Running Code

Navigate to the folder containing the Go file and run:

```bash
go run filename.go
```

Example:

```bash
go run code.go
```

To build an executable:

```bash
go build filename.go
```
